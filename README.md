# TypeScript Beginning

A hands-on learning repository documenting my journey into TypeScript, covering fundamental concepts through practical exercises and coding examples.

## 📌 About This Repository

This repository contains my initial TypeScript learning exercises and practice modules. It focuses on building a strong foundation in TypeScript and understanding how static typing improves JavaScript development.

## 🚀 Topics Covered

- Introduction to TypeScript
- Basic Types
- Type Annotations
- Type Inference
- Functions and Return Types
- Arrays and Tuples
- Objects and Type Aliases
- Interfaces
- Optional and Readonly Properties
- Union Types
- Basic TypeScript Concepts

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Mezba-Morsalin/typescript-beginning.git
```

**2. Navigate to the project**

```bash
cd typescript-beginning
```

**3. Explore the practice files**

Explore the `Module - 01` directory to see the TypeScript exercises and examples.
